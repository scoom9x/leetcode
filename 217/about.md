# About the Solutions

## Intuitive

### Thought Process

> Instead of iterating through the array, and storing the values in a seperate array, checking if the value already exists in that seperate array which would cost us some time, I decided to store the value in key-value pairs in a hashmap so the checking of a membership of certain values is instant.

### Complexities

> - Time Complexity: O(n)
> - Space Complexity: O(n)

## Best

### Thought Process

> Essentially the same as the intuitive one, except we use a set which maps the values in the list without needing a key value pair, which is slightly faster.

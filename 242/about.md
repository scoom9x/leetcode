# About the Solutions

## Intuitive

> ### Thought Process
>
> - Alright so I first thought to sort the characters in each string and compare them but knew that would be too slow
> - I knew that would be too slow, so I instead put the count of the characters in each string into their respective maps
> - I would then compare the two maps to see if they were equal

> ### Efficiency
>
> - Space Complexity: O(n)
> - Time Complexity: O(1)
